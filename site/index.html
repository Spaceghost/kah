02 / Inside the orbit

Good foundations.
A new direction.

Kah builds on work from Ruby’s world and aims toward the Lua ecosystem. Each piece has one clear job.

01

Prism reads the Ruby.

Prism, Ruby’s parser, provides the frontend. The compiler starts with Ruby syntax and a structured AST.

02

Spinel provides the starting point.

Matz’s Spinel already connects Prism to a compiler pipeline. Kah adds a Lua backend alongside that foundation.

03

Lua is the destination.

The target is portable Lua source with Lua 5.1 compatible syntax, shared by standard Lua and LuaJIT. Compile once, choose the VM.

03 / First steps

A small compiler.
Room to grow.

Kah is an early prototype with a working Ruby-to-Lua compiler. The same generated programs are checked against CRuby on Lua 5.1, Lua 5.4, Lua 5.5, and LuaJIT 2.1.

Compile and run, once installed
$ kah hello.rb -o hello.lua
$ lua hello.lua
$ luajit hello.lua

The same generated Lua file, with your choice of VM.
